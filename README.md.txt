Superstore Sales Performance Analysis

Project Overview

This project focuses on analyzing the Sample Superstore dataset using Microsoft Excel to understand sales, profit, and quantity performance.

Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers

Dataset

- Sample Superstore Dataset
- 9,994 records

Analysis Performed

1. Region-wise Sales Analysis
2. Category-wise Sales Analysis
3. Category-wise Profit Analysis
4. Region-wise Sales and Profit Analysis

Dashboard

The dashboard includes:

- Total Sales
- Total Profit
- Total Quantity
- Region-wise Sales Chart
- Category-wise Sales Chart
- Category-wise Profit Chart

Key Metrics

- Total Sales: 2,297,200.86
- Total Profit: 286,397
- Total Quantity: 37,873

Conclusion

This project helped me gain practical experience in Excel-based data analysis, PivotTables, charts, and dashboard creation.
