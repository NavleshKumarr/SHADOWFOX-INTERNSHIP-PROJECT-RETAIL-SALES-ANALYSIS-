Retail Sales Analysis Using Python

Project Overview

This project focuses on analyzing retail sales data using Python. The main objective is to identify sales trends, understand product performance, evaluate profitability, and generate useful business insights through data analysis and visualization.

Project Level

Intermediate – Python

Tools and Technologies

- Python 3.14
- Pandas
- NumPy
- Matplotlib
- Seaborn

Project Files

- "RETAIL SALES ANALYSIS.py" – Python script used for data cleaning, analysis, and visualization.
- "Beginner analysis.csv" – Retail sales dataset used for analysis.

Key Analysis Performed

1. Dataset overview and data inspection.
2. Missing value identification.
3. Duplicate record checking and data cleaning.
4. Total sales, profit, and quantity analysis.
5. Region-wise sales and profit analysis.
6. Category-wise sales and profit analysis.
7. Sub-category profitability analysis.
8. Customer segment analysis.
9. Discount impact on profit.
10. Shipping mode performance analysis.
11. Monthly sales trend analysis.

Data Visualizations

The project generates 7 visualizations:

- Region-wise Sales
- Category-wise Profit
- Sub-category Profit
- Sales by Customer Segment
- Monthly Sales Trend
- Discount vs Profit
- Sales by Shipping Mode

Key Business Insights

- The West region recorded the highest sales and profit.
- Technology was the top-performing category by sales.
- Consumer customers contributed the highest sales.
- Copiers recorded the highest sub-category profit.
- Higher discount levels were associated with negative average profit in some discount groups.
- Standard Class shipping contributed the highest sales and profit.

How to Run the Project

Step 1: Install Required Libraries

pip install pandas numpy matplotlib seaborn

Step 2: Keep Project Files Together

Place the following files in the same folder:

- "RETAIL SALES ANALYSIS.py"
- "Beginner analysis.csv"

Step 3: Check the Dataset Path

Make sure the CSV file path in the Python script points to the correct location of "Beginner analysis.csv".

Step 4: Run the Python Script

Open the Python file in IDLE or another Python editor and run the program.
